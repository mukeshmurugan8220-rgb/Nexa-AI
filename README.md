# 🤖 NexaAI – AI-Powered Advanced Chatbot

### Your Smart AI Assistant 🚀

NexaAI is an AI-powered chatbot application designed to provide intelligent, interactive, and user-friendly conversations. Built using React, Node.js, Express.js, and Google's Gemini API.

## ✨ Features

- 🤖 AI-powered conversations using Google Gemini API
- 💬 Interactive chat interface
- 🆕 Create New Chat
- 📝 Multiple conversation support
- 🎭 Multiple AI personas
- 💻 Code-friendly responses
- 📋 Copy AI responses
- 🌙 Dark and Light mode
- 📱 Responsive user interface
- ⚡ Fast and smooth experience

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS
- Lucide React
- React Markdown

### Backend
- Node.js
- Express.js
- Google Gemini API

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/mukeshmurugan8220-rgb/Nexa-AI.git
```

### 2. Navigate to Project

```bash
cd Nexa-AI
```

### 3. Setup Frontend

```bash
cd client
npm install
npm run dev
```

### 4. Setup Backend

Open another terminal:

```bash
cd server
npm install
```

Configure your `.env` file:

```env
PORT=5000
GEMINI_API_KEY=your_gemini_api_key
```

Start the backend using the development script configured in server/package.json.

**Important:** Never upload your `.env` file or API keys to GitHub.
